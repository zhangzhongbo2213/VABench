# Figure data

Success rates are taken from the supplied manuscript `main_result.csv`, retained
unchanged as `main_result_source.csv`. Overall rates macro-average 14 tasks in
each of three runs; error bars show the sample standard deviation across runs.
Statistics are recomputed from the unrounded per-task run percentages.
This corrects three 0.01-point rounding discrepancies in the source aggregate
SD cells (Luna: 0.71, Sonnet: 1.49, MiniMax: 0.55).

The nine capability percentages come from the manuscript appendix table
`tab:capability-diagnostics`. They pool applicable single- and dual-arm episodes
from one annotated run; Sonnet uses run 2, all other primary models run 1.
Error-free episodes are excluded from ED, OC and PF.

The animation selects the top 10 models by overall three-run task success.
Transitions interpolate the polygon for display only; the held profiles show
the reported scores. Authors and affiliations follow the manuscript front matter.
